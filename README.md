# GSIN Green Building Website

Website source for 深圳金鑫绿建股份有限公司. The Astro + Tailwind site covers steel-structure contracting, prefab steel buildings, Jinxin country-house products, technology research, project cases, and email-based inquiries.

## Requirements

- Node.js 22+
- npm 10+

## Commands

```bash
npm ci --include=optional
npm run dev
npm run verify
```

The site is intentionally configured in local no-index mode because no production domain was included in this delivery. Deployment, hosting, DNS, HTTPS, and inquiry-form services are separate tasks.
